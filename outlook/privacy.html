Privacy

Tracker Item Inserter is a personal Outlook add-in. It reads tracker data from a JSON file the user has access to and inserts a formatted reference into the email the user is composing.

The add-in does not collect, store, or transmit personal data to any third party. Data is fetched directly into the user's browser session and used only to render the list and build the inserted text.
